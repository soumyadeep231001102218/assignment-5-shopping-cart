# Assignment 5: Online Shopping Cart

A professional Online Shopping Cart application built using React Context API and `useReducer` for robust state management.

## Features Included
- **State Management**: Fully implemented using `useReducer` and `Context API` to manage cart state globally.
- **Product List**: Browse available products with images and prices.
- **Cart Operations**: Add items to the cart, remove items, and dynamically update quantities.
- **Coupon System**: Apply valid coupon codes (e.g., `SAVE20`, `SAVE50`) to instantly reduce the cart subtotal by a percentage.
- **GST Calculation**: Automatically calculates 18% GST after any applied discounts.
- **Grand Total**: Real-time calculation of the final checkout price.
- **Premium UI**: Designed with a modern, dark-themed, and responsive layout.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/soumyadeep231001102218/assignment-5-shopping-cart.git
   ```

2. Navigate into the project directory:
   ```bash
   cd assignment-5-shopping-cart
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit the live deployment to view the site: [https://soumyadeep231001102218.github.io/assignment-5-shopping-cart/](https://soumyadeep231001102218.github.io/assignment-5-shopping-cart/)
